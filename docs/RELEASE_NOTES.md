## Morphotype 0.2

A redesigned editor, per-layer materials and a font editor.

### Install on a Mac

1. Download `Morphotype_0.2.0_universal.dmg` below (it runs on Apple silicon and Intel).
2. Open it and drag **Morphotype** into **Applications**.
3. The app isn't notarised yet, so the first time, right-click it and choose **Open**. If macOS says it is damaged, run `xattr -dr com.apple.quarantine /Applications/Morphotype.app` once.

`Morphotype-web.zip` is the same app as a static website: unzip it and serve the folder from any web host.

### What's new

**Editing like a design tool**
- Click to select, drag to move, and use the handles to resize or rotate. ⇧ keeps proportions or snaps angles, ⌥ scales from the centre.
- Smart guides snap to the artboard and other layers, and there's an optional grid.
- Marquee selection, multi-select, align and distribute, flip, lock and hide.
- Groups and merged shapes. Drag layers to reorder them or move them into groups. Right-click menus everywhere.
- **Edit points**: double-click any outline (or press P) to drag bezier points and handles, add points on a line, or make points smooth or sharp.
- **Warp** with Arch, Arc, Bulge, Flag, Rise, Fish, Inflate, Squeeze and Twist presets, plus a 16-point net you drag on the canvas.
- **Break apart** splits text or a traced image into one layer per letter.

**A material for every layer**
- Styles now belong to layers, so a mascot's eyes can be ink while its body is puffy.
- New materials: Sticker, Aura gradient, Holographic, Retro 3D and Flat gradients, alongside Liquid chrome, Glow glass, Puffy, Neon, Glossy glyph and Distressed.
- 34 presets with live previews, and searchable.
- Canvas backgrounds: solid, linear, radial or aura mesh gradients, film grain, and an app-icon tile with gloss, shadow and a holographic rim.
- Cut and Mask apply to the layer directly below, like clipping masks.

**Type mode: design a font**
- An A–Z, a–z, 0–9 and punctuation grid, previewed with your style.
- One-click looks for the whole font: Bitmap, Dot matrix, Soft pixel, Tiles, Rounded, Heavy, Inline, Melting and more.
- Edit any glyph's points or width, or give it its own modifiers. Add any character, including ones the base font lacks, and draw or trace it.
- A live tester that uses the real compiled font.
- Export as .ttf, .woff, or a web font kit (TTF, WOFF, @font-face CSS and a specimen page). You can also install the font on this Mac or use it straight away in Design mode.

**Made for the keyboard**
- ⌘K searches every command, shape, style preset, canvas size and setting.
- Every action has a shortcut. ? shows them all, along with a short guide.
- Settings with instant search (⌘,).

**Other improvements**
- Custom popovers that scroll on their own, a curated colour picker with an eyedropper, a custom icon set, and hidden scrollbars.
- Canvas formats for Instagram posts and stories, YouTube thumbnails, X headers, OG images, app icons and more.
- Export JPG, or copy the image to the clipboard. SVG export now has one path per object, in its own colour.
- New shapes: chat bubble, spiral, flower, arrow, bolt and moon.
- Twelve new templates, including a bitmap poster, Sudo display, a pixel letter, mascot app icons, aura tiles, a holo letter, a retro sign, a YouTube thumbnail and an Instagram quote.
- The window controls line up with the toolbar.

Projects from 0.1 open automatically and are converted to the new format.
